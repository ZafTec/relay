### Clear confirmation when you create a run

Creating a run now brings a prominent confirmation into view, showing its status
and a **View run** action. Keyboard focus moves with the confirmation so the next
step is easy to reach. The page moves instantly, including when reduced motion is
enabled, and retains your inputs for another run.

### Run updates in plain language

Run pages now say **Live updates restored**, **Updates delayed**, or **Offline ·
showing the last saved update** instead of exposing internal synchronization
terms. Cancellation, retry, and usage messages explain what happened and what to
do next. Retrying an unconfirmed request still reuses the original inputs and
request key to prevent duplicate work.
