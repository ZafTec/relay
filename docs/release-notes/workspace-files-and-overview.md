### See your work, manage your workspace

The overview now shows current run counts, recent activity, saved files, and
storage use. Private images and text can be previewed directly, with audio and
video playback on supported files. Downloads request fresh access when needed.
The landing page follows your light or dark theme, and clearer disclosure
controls keep secondary options easy to find.

Workspace owners can add a logo, change its name, or delete a shared workspace
after confirming its handle. Handles stay permanent after creation. Deletion
removes member access and share links immediately, then removes saved files
through storage cleanup. Active runs and uploads must finish first; personal
workspaces remain available. Each workspace has a **100 MB** storage allowance.
Existing files above that allowance are retained; new uploads need free space.

### Bring files and agents together

Upload files from a public URL in the dashboard or with
`relay.artifacts.import_url`. Relay validates the destination and file, then
saves a copy in workspace storage. URL imports support files up to **20 MB**;
private network addresses and destinations requiring sign-in are rejected.

Connected apps now include automatically registered clients such as Claude.
Disconnect an app to revoke its access; connecting it again never revives an
old disconnected token. Profile photos can be uploaded, linked by URL, or
chosen from a connected Google or GitHub account. Provider photos retain their
original hosted URL.

Superadmins can use MCP to create, review, and publish the in-app changelog.
Publishing requires explicit admin permissions and a recent sign-in. Existing
agent connections remain supported during the database upgrade.
