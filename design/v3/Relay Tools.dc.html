image.generate

v3 · PUBLISHED

Text-to-image generation. Accepts a prompt and returns one to four output artifacts. Two provider models are available; pick one explicitly or accept the default routing policy.

Provider / model options

Model Meter p50 latency Max outputs Reference image

Input schema

{
  "prompt": "string, required, max 2000 chars",
  "negative_prompt": "string, optional",
  "aspect_ratio": "1:1 | 16:9 | 9:16, default 1:1",
  "output_count": "integer 1-4, default 1",
  "seed": "integer, optional",
  "reference_artifact_id": "string, optional, Aurora Fast only",
  "provider_model": "halide-xl | aurora-fast, optional"
}

Limits, safety, estimate method

  • ■ Prompts are checked against a safety policy before submission; rejections do not retry.
  • ■ Estimate is exact for Halide XL (fixed per-output price) and ranged for Aurora Fast (depends on resolved megapixels).
  • ■ Concurrency: 4 running attempts per workspace for this tool.
