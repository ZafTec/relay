// 01 Tool registry for agents

Curated tools. Durable artifacts. Managed delivery.

Relay is a curated registry of tools an agent can discover and call. Every call runs asynchronously, every output persists as a versioned artifact, every run is metered, and every result leaves as a Relay-managed URL — never a raw provider link.

// 03 The golden path

Call the tool. Track the work. Share the result.

An agent reads the tool's schema, submits a run, and polls or streams its state. A person does the same thing from the dashboard. Both end at the same durable artifact.

  1. 01Browse the catalog and inspect a tool's contract and meter unit.
  2. 02Estimate the cost, then run — a reservation is held before any provider is called.
  3. 03Observe the run's state and attempts until it reaches an output set.
  4. 04Share an artifact with a revocable managed link, not a raw store URL.
MCP TOOL CONTRACT · image.generate v3 
{
  "name": "image.generate",
  "version": 3,
  "input_schema": {
    "prompt": "string, required",
    "negative_prompt": "string?",
    "aspect_ratio": "1:1 | 16:9 | 9:16",
    "output_count": "int, 1-4",
    "provider_model": "halide-xl | aurora-fast"
  },
  "meter_unit": "per_output",
  "result": "run_id, output_set[]"
}

// 04 Failure and metering are proof

Retries only when it's safe. Metering that survives failure.

A run that fails before reaching the provider retries free. A run that fails on a schema, safety, or policy check never retries automatically — the input has to change. A run confirmed with the provider but lost on retrieval is reconciled, never blindly resubmitted.

  • ■ Estimate before run, reservation held, usage settled after
  • ■ Reservation released in full on early failure
  • ■ Retry classification, not blanket retry-everything
