Quickstart

Store a file, turn it into a versioned asset, run a job against it, and hand out a signed URL. Four calls, no SDK required.

10 MINUTES NEEDS A WORKSPACE CURL OR MCP CLIENT

01 · Request an upload URL

Relay signs a PUT against your configured store. The URL is scoped to your workspace prefix and expires in fifteen minutes.

POST /v1/uploads
CURL MCP 
curl -X POST https://api.relay.zaftech.co/v1/uploads \
  -H "Authorization: Bearer $RELAY_TOKEN" \
  -d '{"key":"renders/quarterly-map.png"}'

200 { "url": "https://…", "expires_in": 900 }

02 · Commit it as a version

After the PUT succeeds, commit the object. It becomes the newest version of a named asset; earlier versions stay readable.

■

Note

Commit is idempotent per checksum. Committing the same bytes twice returns the existing version rather than creating a duplicate.
