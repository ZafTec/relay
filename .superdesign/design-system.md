# Relay design system

Relay is a corporate technical product by ZafTech for durable MCP storage,
observable background work, immutable asset versions, and signed result
delivery.

## Brand

- Product: Relay
- Parent lockup: Relay by ZafTech
- Domain: relay.zaftech.co
- Public landing: `/`
- Authenticated product: `/dashboard`

## Voice

Direct, restrained, operational, and specific. Use short sentences and concrete
implementation detail. Avoid hype, unsupported metrics, invented customers, and
generic AI language.

Primary line: “Files in. Work underway. URLs out.”

## Color

- Onyx background: `#101410`
- Surface: dark green-black slightly above onyx
- Primary text: warm ivory
- Muted text: desaturated green-gray
- Primary accent: spruce `#7CC8B8`
- Secondary emphasis: restrained copper
- Error: clear warm red

Use accent color to communicate state or action, not as decoration.

## Typography

- Headings and body: Plus Jakarta Sans
- Operational labels, endpoints, dates, versions, code, and status: JetBrains
  Mono or the available mono equivalent
- Tight display headings; readable body line-height; uppercase mono kickers used
  sparingly

## Geometry

- Mostly square corners
- One-pixel borders
- Technical 48px-style grid where useful
- Minimal shadow
- No glassmorphism
- No large decorative gradients
- No floating 3D blobs
- Generous negative space and strict alignment

## Assets

Prefer custom SVG diagrams and real product captures. The core visual is
movement through durable stages:

`input -> object -> immutable versions -> queued job -> result -> signed URL`

Create a coherent thin-line icon language. Do not use stock cloud or data-center
photography.

## Motion

Sparse and purposeful: status progression, connector-line drawing, small reveal,
and subtle button press. Keep routine interactions fast and respect reduced
motion.

## Accessibility

High contrast, visible focus, 44px controls, semantic hierarchy, readable code,
and redundant status labels so color is never the only signal.
